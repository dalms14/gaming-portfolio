# Daniel Almojera - Portfolio

A standalone gaming-themed portfolio built with HTML, CSS, and JavaScript. It is separate from FLUX-POS. No installation or build step is needed.

## Open

Double-click index.html. Alternatively, run `python -m http.server 5500 --bind 127.0.0.1` in this folder and visit http://127.0.0.1:5500.

## Content

Personalized from the supplied resume: bio, skills, education, training, FLUX capstone, email, and GitHub. The FLUX visual is a technology diagram, not a screenshot of the application. No project demo or repository URL has been invented.

The assets folder contains the two supplied portraits and an unchanged copy of the supplied resume. The profile buttons switch between portraits; resume links download the PDF.

## Edit

- index.html: page copy, headings, skills, education, and project layout.
- script.js: name, handle, email, project dialog text, and portrait selection.
- style.css: colors, responsive styles, and motion.
- assets/: portraits and resume.

Includes scroll progress, controller parallax, section reveals, mouse tilt, and keyboard-accessible project details. Reduced-motion preferences disable animations. Content and contact links remain usable without JavaScript. No external assets, analytics, or build dependencies are required.


## Game worlds

The Worlds section includes five original SVG tributes: God of War, Ghost of Tsushima, Hollow Knight, Minecraft, and Valorant. Choose a game or use Next world to update its scene, typography, accent palette, and atmospheric effects. The active artwork moves subtly with scrolling. Reduced-motion preferences disable scene motion and particles.

Scene files are editable vectors in assets/worlds/. Game configuration and selection logic are in script.js. A noscript gallery exposes the other illustrations when JavaScript is disabled. These are original illustrated tributes, not official screenshots or assets.
